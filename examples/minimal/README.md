# 起步示例（3 条判断 · 一个虚构人物）

这是刚聊两轮能拿到的东西——**还不是 L0**（3 条判断覆盖 3 个域；L0 要 8 个域各 1 条）。
它已经能立刻用：把这个目录给任何 AI，它就不会再问"你是做什么的"。

人物纯属虚构，用来展示格式。

| 文件 | 说明 |
|---|---|
| `PORTRAIT.md` | 人读版：每条判断都有上下文和依据编号 |
| `CONTEXT.md` | AI 读版：30 行，只有结论和雷区 |
| `facts.jsonl` | 4 条原话（都带 `asked`） |
| `claims.jsonl` | 1 条背景 + 2 条状态 + 3 条判断 |
| `tensions.jsonl` / `drafts.jsonl` | 空（这个规模还不会有） |
| `state.json` | 断点：第 2 轮，下一域 work |
| `CHANGES.md` | 最近一次 build 相对上一次的变化 |

**看不出来但重要的两件事**：

1. 每条判断的 `context` 里都嵌了依据原话的连续 8 个字——这是机器校验的，不是自觉。
2. `review_after` 是按 `type` 算出来的（状态 90 天、判断 365 天），不是手填的。

想看怎么从零到这里，读仓库根目录的 `AGENTS.md`：一轮 = 4–5 个问题 + 一次 `commit.py`。
