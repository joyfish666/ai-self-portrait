# 自我画像 · ai-self-portrait

> **你和 AI 聊完，得到一段对话。用这个仓库，得到一个文件。**
> **对话会消失，文件不会。**

文件跟着你十年，能被任何 AI 读取，能被 git 记录，能在你说错自己时反驳你。

---

## 为什么会有这个仓库

我们把它重构了三次，才发现画像为什么会烂：

| 坏习惯 | 结果 |
|---|---|
| 同一个事实写在好几个地方 | 改一处，别处留旧版 |
| 用"追加"去处理"修改" | 正文写满"已纠正""作废" |
| 没有闸门，靠自觉 | 漂移攒到看不下去，才大重构一次 |

**结论：个人画像不是文档，是一组会过期的判断。**
用写文章的方式维护它，三周就烂。

**这个仓库就是那三次重构的结论。**

## 30 秒开始

需要 **Python 3.8+**（只用标准库，不用装任何东西）。

```bash
git clone <this-repo> my-portrait
cd my-portrait
python scripts/init.py
```

在 agent（如 DeepSeek Harness / Cursor / Claude Code）里打开这个目录，然后说：

> **请阅读这个项目，帮我构建一个我个人用户画像**

它会读 `AGENTS.md`，按 `PROTOCOL.md` 一轮轮问你，每轮 4–5 个问题。

**聊两轮就有一份能用的画像**，聊到十轮就能拿去做复盘。

> **代理不直接改数据文件。** 每轮它只交一份 JSON，由 `scripts/commit.py` 校验、编号、写盘、出对账单。
> 校验不过的进草稿区，不会污染正式层，也不会丢。

## 你会得到什么

两个文件：

| 文件 | 给谁 | 长什么样 |
|---|---|---|
| `me/PORTRAIT.md` | 你自己 | 有上下文、有因果、能逐条反驳 |
| `me/CONTEXT.md` | AI | ≤150 行，只有结论和雷区 |

示例（`examples/minimal/`，刚开始几轮的效果）：

```markdown
### 最怕一直在给别人做东西

他说"最怕一直在给别人做东西，自己什么都没留下"——怕的是没有属于自己的产出。

`confirmed` · `disposition` · 复核 2027-11-05 · 依据 1 条（f-0002）
```

**注意那条 `依据 1 条（f-0002）`**——点开能看到你的原话。**判断永远可以追溯到证据。**

## 它凭什么不烂

八条保证，每条都有对应的机制：

| # | 保证 | 机制 |
|---|---|---|
| G1 | 写入即合法 | **只走 `commit.py`**：Schema + 引用 + 片段 + 日期 + 去重；不合格进草稿区 |
| G2 | 视图零维护 | 视图只由脚本生成；`check` 比对视图哈希，手改当场报错 |
| G3 | 中断即完整 | L0/L1/L2 分层 + `state.json` 断点 |
| G4 | 过期必可见 | `review_after` 由 `type` 算出（状态 90 天 / 判断 365 天）+ ⏳ 标记 |
| G5 | 零概念负担 | 你只做两件事：回答、否决 |
| G6 | 上限自约束 | 判断 ≤60 / 状态 ≤40；超了**整批拒绝**，什么都不写 |
| G7 | 一秒体检 | `check.py`，纯代码，不调 LLM |
| G8 | 不静默丢失 | 每条输入有终态；对账单里的"丢失"是**减法算出来的**，不是承诺 |

**核心设计只有一句：无限的证据 + 有限的判断 + 永远重算的视图。**

## 文件说明

| 文件 | 说明 |
|---|---|
| `AGENTS.md` | **代理入口**：触发词、流程、硬规则 |
| `PROTOCOL.md` | 访谈协议：问什么、怎么问、何时停 |
| `SPEC.md` | 数据格式与八条保证的完整规范 |
| `template/` | 空画像骨架 |
| `scripts/init.py` | 初始化 `me/`，并给 `me/` 建一个 git 仓 |
| `scripts/commit.py` | **唯一写入路径**：校验、编号、草稿、写盘、出对账单 |
| `scripts/build.py` | 渲染两个视图 |
| `scripts/check.py` | 一秒体检 |
| `scripts/synth.py` | 综述层：写作工作台 + 引用校验 |
| `scripts/selftest.py` | 自测：用虚构数据把八条承诺逐条验一遍 |
| `scripts/digest.py` / `suggest.py` / `tension.py` | 消化、依据召回、矛盾工作台 |
| `examples/minimal/` | 起步阶段的完整示例（覆盖 4 个域，不是完整 L0） |
| `me/` | **你的数据（被 gitignore，不会提交；但它自己是一个 git 仓）** |

## 隐私与备份

- **`me/` 被根目录 `.gitignore` 排除**，不会被推到 GitHub
- 但 `me/` **自己是一个 git 仓**（`init.py` 建）：每轮 `commit.py` 自动提交一次
- 所以备份 = 给 `me/` 加一个私有远端：`cd me && git remote add origin <你的私有仓> && git push -u origin main`
- **不要**在根仓里 `git add me/`——它被 ignore 了，`git add -A` 什么也加不进去
- **不会主动问**姓名、证件、住址、别人的私事——那类问题最让人别扭
- 你自己说到的，**照实记**（反正只在本地），AI 不会追问，也不会替你传播
- 纯本地，无账号、无服务端、无同步
